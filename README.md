
# Post Management API

A RESTful Web API built using ASP.NET Core, demonstrating clean CRUD architecture with Entity Framework Core and SQL Server.

## Features
- Full CRUD operations (Create, Read, Update, Delete) for Posts
- Entity Framework Core with SQL Server integration
- Swagger / OpenAPI documentation
- Data validation using Data Annotations
- RESTful routing conventions

## Tech Stack
- ASP.NET Core Web API
- Entity Framework Core
- SQL Server
- Swagger (Swashbuckle)

## Getting Started
Clone the repo, update the connection string in `appsettings.json`, run EF Core migrations, and start the application.
